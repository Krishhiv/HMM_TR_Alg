--------------------------------------------------------------------------------
  METHODOLOGY NOTES
--------------------------------------------------------------------------------
  * Walk-forward: HMM retrained every 30 days on a trailing 730-day window.
    No parameters fit on the test period; fully out-of-sample from 2022-01.
  * Causal regime signal: state for day T decoded only from data <= T-1.
  * Vol-target: daily position scaled by min(0.40 / BTC_realized_vol, 1.0),
    realized vol = 20-day close-to-close, annualized, lagged 1 day.
    Scale range observed: 0.39x - 1.00x (mean 0.82x). Never levers above 1.0x.
  * Sharpe/Sortino annualized with sqrt(365) on daily returns.
  * Returns are net of the strategy's per-bar cost model; no funding/borrow.

  Reproduce:
    python scripts/run_portfolio.py --vol-target 0.40 --vol-max-scale 1.0 \
        --out-dir outputs/portfolio_voltarget40
